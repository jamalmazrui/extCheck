# extCheck Hotkeys

The keys of the extCheck dialog, listed three ways. Each Alt key is the letter underlined in its control's label, so a screen reader reads it with the control. OK and Cancel have no letter: Control+Enter is OK and Escape is Cancel, from any control, and Enter is OK except on a button. The dialog is built with the Homer Lbc classes, so every text field also has the Lbc editing keys; Help (F1) lists them.

## By key

- Alt+B — Browse local source
- Alt+C — Choose output directory
- Alt+Control+X — open the extCheck dialog from anywhere (the desktop shortcut)
- Alt+D — Default settings
- Alt+F — Force replacements
- Alt+H — Help
- Alt+O — Output directory
- Alt+S — Source paths
- Alt+U — Use configuration
- Alt+V — View output directory
- Control+Enter — OK, from any control
- Enter — OK: start the check
- Escape — Cancel, from any control: close without checking
- F1 — Help
- F11 — check for a newer version, from any control
- F7 — list the dialog's controls, and move to the one chosen
- Shift+F1 — say the focus tip for the current field
- Shift+F10, then X — Report via extCheck, on a file in File Explorer

## By command

- Browse local source — Alt+B
- Cancel — Escape
- Check for a newer version — F11
- Choose output directory — Alt+C
- Default settings — Alt+D
- Force replacements — Alt+F
- List the controls — F7
- Help — Alt+H or F1
- OK — Enter, or Control+Enter from any control
- Open the dialog from anywhere — Alt+Control+X
- Output directory — Alt+O
- Report via extCheck, in File Explorer — Shift+F10, then X
- Say the focus tip — Shift+F1
- Source paths — Alt+S
- Use configuration — Alt+U
- View output directory — Alt+V

## In tab order

The dialog is in bands, rows read left to right, in this order:

1. Source paths — Alt+S
2. Browse local source — Alt+B
3. Output directory — Alt+O
4. Choose output directory — Alt+C
5. Force replacements — Alt+F
6. Use configuration — Alt+U
7. View output directory — Alt+V
8. Default settings — Alt+D
9. Help — Alt+H or F1
10. OK and Cancel, alone at the bottom right: Control+Enter is OK and Escape is Cancel, from any control

## Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because "elevate" sounds like "eleven". Alt+Control+X belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts. X is the sound that starts extCheck's name, and the same letter is the access key of Report via e**x**tCheck in File Explorer, so one letter reaches extCheck both ways.
